# 10/07 오늘 한 일

브랜치: `feat/subscription-score` · 대상: 팀원 (리뷰·실행하는 사람)

## 한 줄 요약

상/중/하 판정에 쓰는 두 숫자를 모두 고쳤다. **내 점수**는 국토부 가점표로, **공고 기준 커트라인**은 회귀 모델로.
2025~2026년 공고(1,023건)에서 커트라인 평균 오차가 14.47점에서 12.86점으로 11% 줄었고, 상/중/하 일치율은 66.3%에서 70.2%로 올랐다.

## 1. 가점표 (REQ-04의 "가점은 임시식" 해결)

- `services/eligibility_filter.py`: 무주택기간(32점)·부양가족(35점)·통장 가입기간(17점)을 국토부 가점표 구간대로 계산한다.
- 예: 무주택 3년, 부양가족 0명, 통장 3년 → 예전 12점, 지금 18점.
- 구간 경계값을 `tests/test_eligibility_filter.py`로 확인한다.
- 남은 한계: 만 30세 미만 미혼의 무주택기간 0점 규칙은 프로필에 나이·혼인 여부가 없어 반영하지 못했다.

## 2. 커트라인 회귀 모델

- 예측 대상: 주택형별 **해당지역 최저 당첨가점**(커트라인). 학습 데이터 7,022행(2020~2026).
- 학습 2020~2024년, 채점 2025~2026년. 앱은 앞으로 나올 공고를 예측하므로 연도로 나눴다.
- 접수가 끝나야 아는 값(경쟁률·신청 건수)은 특징에서 뺐고, 과거 기록은 그 공고 연도 이전 3년만 쓴다.

| 방법 | 커트라인 MAE (낮을수록 좋음) | 상/중/하 일치율 |
|---|---|---|
| 베이스라인 (직전 3년 평균) | 14.47 | 66.3% |
| Ridge 선형회귀 | 13.79 | 67.9% |
| 랜덤포레스트 | 14.51 | 65.8% |
| **그래디언트 부스팅 (채택)** | **12.86** | **70.2%** |

- `services/probability_estimator.py`: 기준 커트라인으로 모델 예측값을 먼저 쓰고, 모델 파일이 없거나 APT 분양이 아니면 예전 3년 평균을 쓴다.
- `api/routes/recommendations.py`: 모델은 공고마다 값이 달라서 (지역, 평형) 캐시를 뺐다.
- 평가 결과는 `backend/models/cutoff_reg_metrics.json`, 자세한 설명은 `docs/261007_12_…결과보고서.pdf`.

## 알게 된 것

- **미달(커트라인 0점)이 오차의 큰 부분이다.** 검증 공고의 14.5%가 미달이고(해마다 늘어 2020년 6% → 2026년 15%), 이 공고들의 오차가 약 35점이다. 전체 오차 12.9점 중 약 5점이 여기서 나온다.
- **과적합은 있지만 해롭지 않다.** 부스팅은 학습 데이터에서 6.98점, 처음 보는 데이터에서 12.86점 틀린다. 하지만 학습을 늘려도 검증 오차가 끝까지 줄어든다. 랜덤포레스트는 학습 6.95점/검증 14.51점으로 해로운 과적합이라 쓰지 않았다.
- **새 정보를 더해도 전체 오차는 더 줄지 않아서 v1(위 표의 그래디언트 부스팅)을 채택했다.** 동·시공사·시행사의 과거 기록과 앙상블을 더한 v2는 미달이 아닌 공고의 오차는 9.17 → 8.59점으로 줄지만, 미달 공고의 오차가 34.7 → 39.0점으로 늘어 전체는 12.86 → 13.03점으로 같은 수준이었고 특징 83개·과거 기록 저장으로 훨씬 복잡하다. v2 코드는 커밋 `4ab76cc`에 남아 있다 (`git show 4ab76cc:backend/app/services/cutoff_model.py`).
- **v1의 한계:** 3개 모델 중 하나를 고를 때 채점용 데이터(2025~2026년)를 썼다. 후보 사이 차이가 커서(부스팅 12.86 vs 나머지 13.8~14.5) 결론이 바뀔 가능성은 낮지만, 12.86은 실제보다 조금 좋게 나온 숫자일 수 있다.
- 2023년 검증에서는 모델이 예전 방식과 비슷했다(학습 데이터가 적고 시장이 바뀐 해). 최근 연도에서만 확실히 낫다.

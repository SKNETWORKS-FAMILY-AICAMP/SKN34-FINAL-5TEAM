# 커뮤니티 시연 데이터 경계

실제 계정 로그인 이후 사용하는 브라우저 전용 시연 기능입니다. 백엔드 커뮤니티 DB나 청약 진단에는 가짜 데이터를 저장하지 않습니다.

- 공통: `cheongyak:community-demo:v3:public`에 게시판, 글, 댓글, 공감·조회 수와 공개 프로필을 보관합니다. 작성자는 계정에 고정되며 각 화면에서 본인만 author=0으로 투영합니다.
- 개인: 기존 `v2:account:user-ID`에 친구·친구 요청·쪽지·스크랩·공감 여부·차단·신고·알림·설정을 보관합니다. 새싹만 기존 개인 시연 데이터를 받습니다. 관리자와 일반 계정도 공통 게시판에 접근할 수 있지만 새싹의 개인 활동을 상속하지 않습니다.
- 이전 데이터: 계정 소유자가 확인되는 v2 글과 댓글을 한 번만 공통 저장소로 옮깁니다. 기존 키는 삭제하지 않습니다. 소유자 없는 standalone 저장소는 자동 합치지 않습니다.
- 첨부: 개인 계정별 IndexedDB를 유지합니다. 글·댓글에 공개한 파일만 별도 published DB로 복사합니다. 쪽지 파일은 공유하지 않습니다. 개인 활동 초기화는 공개 글·댓글·파일을 삭제하지 않습니다.
- 다른 탭: 공통 저장소 변경 시 게시판을 다시 읽습니다. 이전 화면이 친구·설정 등을 저장할 때 다른 계정의 글·댓글을 덮어쓰지 않도록 변경분을 병합합니다.

공유 범위는 **동일 출처·동일 브라우저 프로필**입니다. 다른 기기·브라우저 간 동기화나 실제 쪽지 전송, 관리자 운영 권한은 구현하지 않습니다. localStorage는 인증·권한 시스템이 아니므로 운영 서비스에는 서버 인증과 소유권 검증이 필요합니다.

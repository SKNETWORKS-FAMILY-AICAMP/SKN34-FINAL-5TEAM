# 수집 데이터 보고서

작성일 2026-10-02. 수치는 팀 DB 가이드(2026-09-30)와 로컬 수집 코드를 기준으로 한다.

## 출처

| 출처 | 받은 것 | 못 받은 것 |
|---|---|---|
| 청약홈 공공데이터 | 공고·주택형·경쟁률·당첨가점·특별공급. 2020년 이후 | 자격 요건 숫자, 단지별 계약금 비율(PDF) |
| 금융감독원 파인 | 주택담보·전세자금 상품과 금리 옵션 | 정책대출 디딤돌 등 공식 한도 API |
| SH 게시판 | 분양·임대 최근 페이지 목록 | 첨부 공고문 금액 |
| LH | 수집 코드는 있음 | 키 403이면 0건 |

## 저장

- 원본: `listings`, `historical_results`, `loan_products`, (`loan_rate_options`는 팀 브랜치)
- 사용자 입력: `user_profiles` (수집과 무관)
- 갱신: 서버가 켜져 있으면 6시간마다 청약홈 최신 + LH·SH·파인 ([scheduler.py](../backend/app/data_pipeline/scheduler.py))

## 전처리

원본 행을 지우지 않는다. 서비스 값은 읽기 전용으로 계산한다.

- 계약금 가정치 = 분양가 × 10%
- D-day = 접수 시작·종료·발표일 − 오늘
- 추천은 희망 지역 + 자격 정렬, 최대 50건

## 라이선스·개인정보

공공 API 이용약관을 따른다. 키는 `backend/.env`만 쓴다. 사용자 자산은 프로필 테이블에 있으며 목록 API는 만들지 않는다.

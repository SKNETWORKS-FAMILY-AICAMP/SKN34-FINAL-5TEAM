### ✅ 현재 정한 기준
1. **용어와 사용법을 찾아보며 만들기**
   - 느리더라도 정확하게 익히기
   - AI가 작성한 코드도 이해하고 설명할 수 있도록 하기

2. **AI에만 의존하지 않기**
   - 급하더라도 전부 AI로 해결하지 않기
   - 직접 작성하고 오류를 해결하는 경험 쌓기

3. **실제로 사용할 수 있는 앱인가?**
   - 이 앱이 출시되면 사람들이 사용할까?
   - 내가 직접 사용하고 싶은가?

4. **내가 가장 불편했던 문제에서 출발하기**
   - 내가 겪은 불편함
   - "이런 게 있었으면 좋겠다"라는 생각
   - 실제 문제를 해결하는 서비스 만들기

---


**① 문제를 구체적으로 정의하기**

"이런 앱이 있으면 좋겠다"에서 끝나지 않고,

- 어떤 상황에서 불편했는가?
- 지금은 어떻게 해결하고 있는가?
- 기존 서비스로는 왜 부족한가?
- 이 앱이 있으면 무엇이 편해지는가?

예를 들어 네가 생각했던 **1인 창업자 세금·지원금 서비스**라면,

> 1인 창업자가 자신에게 맞는 지원금과 세금 정보를 찾기 어려운 문제를 해결한다.

이렇게 문제를 한 문장으로 정리할 수 있어.

---

**② 실제로 필요한 기능인지 확인하기**

기능을 많이 넣는 것보다 핵심 기능이 중요해.

각 기능을 추가하기 전에 물어봐.

> "이 기능이 없으면 사용자가 정말 불편할까?"

- 핵심 기능
- 있으면 좋은 기능
- 나중에 추가할 기능

이렇게 나누면 프로젝트가 지나치게 커지는 걸 막을 수 있어.

---

**③ AI가 없어도 이해할 수 있는 구조로 만들기**

AI를 사용하지 말라는 뜻은 아니야.

AI를 활용하되 다음 과정을 거치는 거야.

1. 내가 만들 기능을 먼저 정리
2. 필요한 기술과 용어 검색
3. AI에게 코드 작성 도움받기
4. 코드 한 줄씩 이해하기
5. 직접 실행하고 오류 해결하기
6. 내가 만든 기능을 설명할 수 있는지 확인

특히 너는 아직 배운 지 약 3개월 정도니까, **AI를 활용하면서 이해하는 능력을 키우는 방향**이 현실적이야.

모든 코드를 처음부터 직접 작성해야 하는 건 아니야.

---

**④ 실제 사용자에게 필요한 서비스인지 확인하기**

네가 사용하고 싶다는 건 좋은 출발점이야.

다만 네가 불편하다고 해서 다른 사람도 반드시 필요로 하는 건 아니거든.

가능하다면 주변 사람 2~3명에게 물어봐.

- 이런 불편함을 겪어본 적이 있는지
- 지금 어떻게 해결하는지
- 이런 앱이 있다면 사용할 것인지
- 어떤 기능이 가장 필요한지

처음부터 대규모 설문조사까지 할 필요는 없어.

---

**⑤ 완성할 수 있는 규모인지 확인하기**

이 부분은 특히 중요해.

네가 배우는 과정에서 프로젝트가 너무 커지면 기능보다 기술 공부에 지칠 수 있어.

처음에는 다음 정도로 정해봐.

| 구분 | 확인할 내용 |
|---|---|
| 목표 | 이 프로젝트로 무엇을 해결할까? |
| 핵심 기능 | 반드시 구현할 기능 1~3개 |
| 기술 | Python, DB, LLM 등 필요한 기술 |
| 기간 | 어느 정도 기간에 완성할까? |
| 완성 기준 | 어떤 상태면 프로젝트가 끝났다고 할까? |
| 학습 | 새롭게 익힌 용어와 기술 |
| 기록 | 오류, 해결 방법, 배운 점 |

### ⭐ 내가 생각하는 가장 중요한 기준

네 프로젝트를 시작하기 전에 이 질문을 꼭 해봤으면 좋겠어.

> **"이 프로젝트를 3개월 뒤에도 내가 직접 사용하고 있을까?"**

그리고 하나 더.

> **"이 프로젝트를 면접에서 내가 직접 설명할 수 있을까?"**

두 가지 모두 중요해.

다만 처음부터 완벽한 앱을 만들려고 하면 부담이 커질 수 있으니까,

**내가 필요한 문제 → 작은 기능 구현 → 사용해 보기 → 개선하기**

이 순서로 진행하면 좋아.

---

### 마지막으로 하나 추가한다면

**⑥ 프로젝트를 통해 내가 무엇을 배우고 싶은지 정하기**

예를 들면:

- Python 코드 이해
- 백엔드 API 구현
- DB 데이터 저장 및 조회
- LLM 연동
- GitHub 관리
- 배포와 실제 사용

프로젝트 하나에 모든 기술을 다 넣을 필요는 없어.

네가 지금 가장 배우고 싶은 기술 2~3개를 정하고, 나머지는 프로젝트 진행에 맞춰 추가해도 돼.

---

내가 궁금한 건 하나야.

**이번 개인 프로젝트는 어떤 방향이야?*

좋아. 그러면 네 프로젝트는 **전월세 정부 지원금이라는 실제 문제를 해결하면서, 네가 직접 사용하고 AI 엔지니어 취업에도 도움이 되는 서비스**를 목표로 하면 좋겠어.

네가 정한 3가지 기준을 모두 충족하는 방향으로 정리해 볼게.

## 1️⃣ 전월세 정부 지원금 서비스에 추가할 아이디어

단순히 지원금 정보를 알려주는 서비스보다 **"나에게 맞는 지원 제도를 찾고, 신청까지 준비하도록 도와주는 서비스"**로 확장하면 좋아.

### 🏠 핵심 아이디어

**개인 맞춤형 전월세 지원금 탐색 및 신청 준비 AI 서비스**

사용자가 자신의 상황을 입력하면 관련 지원 제도와 신청 준비 정보를 제공하는 거야.

예시:
> 나는 서울에 사는 29세 1인 가구이고, 월세 50만 원을 내고 있어. 받을 수 있는 지원금이 있을까?

AI가 다음과 같이 안내하는 거지.

- 내가 신청할 가능성이 있는 지원 제도
- 지원 대상 조건
- 소득·재산·나이 등 확인해야 할 조건
- 예상 지원 내용
- 신청 기간
- 필요한 서류
- 공식 신청 사이트

⚠️ 지원 가능 여부는 공식 기준과 사용자의 정보 확인이 필요하므로, AI가 무조건 받을 수 있다고 단정하면 안 돼.

---

## 2️⃣ 여기에 덧붙이면 좋은 기능

처음부터 전부 구현하지 말고, **핵심 기능과 확장 기능을 나누자.**

| 기능 | 설명 | 우선순위 |
|---|---|---|
| 맞춤형 지원금 검색 | 사용자 조건에 맞는 지원 제도 찾기 | ⭐ 핵심 |
| 지원 자격 확인 | 나이, 소득, 거주지 등 조건 점검 | ⭐ 핵심 |
| AI 챗봇 | 지원 제도에 대해 질문하고 답변 | ⭐ 핵심 |
| 공식 정보 출처 | 정책 원문 및 신청 링크 제공 | ⭐ 핵심 |
| 신청 서류 안내 | 필요한 서류와 준비 방법 안내 | 높음 |
| 지원금 비교 | 여러 제도의 조건·혜택 비교 | 높음 |
| 사용자 정보 저장 | 반복 입력 없이 내 조건 관리 | 중간 |
| 신청 준비 체크리스트 | 준비한 서류를 체크 | 중간 |
| 정책 변경 확인 | 지원 제도 변경 여부 확인 | 나중에 |

### 💡 내가 특히 추천하는 추가 아이디어

**"내 상황에서 어떤 지원금을 먼저 확인해야 할까?"**

단순 검색이 아니라 우선순위를 정해 주는 거야.

예를 들어:
> 현재 입력하신 조건을 기준으로 다음 3개 제도를 먼저 확인해 보세요.

단, 우선순위는 실제 자격 요건과 신청 기간을 바탕으로 설명해야 해.

이 기능을 잘 구현하면 검색 서비스에서 **개인 맞춤형 의사결정 보조 서비스**로 발전할 수 있어.

---

# 3️⃣ AI 엔지니어 취업용 기술 구성

네가 배우고 있는 내용을 기준으로 너무 복잡하게 시작하지 않는 걸 추천해.

### 1단계: 기본 서비스 구현

먼저 AI 없이도 작동하는 기본 기능을 만들어.

```text
사용자 조건 입력
      ↓
지원금 데이터 조회
      ↓
조건에 맞는 지원금 필터링
      ↓
지원금 목록 출력
```

배울 수 있는 것:
- Python
- 백엔드 API
- DB
- 조건문 및 데이터 처리

### 2단계: AI 챗봇 추가

```text
사용자 질문
      ↓
관련 지원금 정보 검색
      ↓
LLM에 정보 전달
      ↓
답변 생성
```

여기서 RAG를 적용할 수 있어.

**RAG란?**
AI가 미리 저장된 정부 지원금 자료를 검색한 뒤, 그 내용을 바탕으로 답변하도록 하는 방식이야.

배울 수 있는 것:
- LLM API
- 프롬프트 작성
- 임베딩
- 벡터 DB
- RAG
- 답변 정확성 검증

처음부터 벡터 DB를 넣기보다는 기본 검색부터 구현해도 괜찮아.

### 3단계: 실제 서비스화

```text
프론트엔드
    ↓
백엔드 API
    ↓
DB + 지원금 데이터
    ↓
검색 / 자격 조건 확인
    ↓
LLM 답변
```

추가로:
- Docker
- GitHub
- 배포
- 오류 처리
- 로그 관리

등을 공부할 수 있어.

---

# 4️⃣ 네가 직접 사용하고 싶은 서비스인지 확인

이 부분은 네가 정한 기준과 가장 밀접해.

프로젝트 시작 전에 다음 질문에 답해 봐.

### 사용자 입장

- 내가 전월세 지원금을 찾을 때 실제로 불편했던 점은?
- 여러 사이트를 직접 찾아야 했는가?
- 내 조건에 맞는 지원금인지 판단하기 어려웠는가?
- 신청 서류를 준비하는 과정이 복잡했는가?
- 이 서비스를 다시 사용할 이유가 있는가?

### 개발자 입장

- 내가 구현한 코드를 설명할 수 있는가?
- AI가 틀린 답변을 했을 때 어떻게 확인할 것인가?
- 정부 정책이 변경되면 데이터를 어떻게 업데이트할 것인가?
- 개인정보를 저장한다면 어떻게 보호할 것인가?

특히 **정부 지원금 서비스는 정보의 최신성과 정확성이 중요해.**

---

# 5️⃣ 프로젝트 아이디어를 더 발전시키는 방향

내가 네 아이디어에 추가한다면 이 기능을 고려할 것 같아.

### 🏡 "이사 전 지원금 확인 도우미"

전월세 계약을 준비하는 사람을 대상으로 하는 거야.

예시:

> 서울에서 월세방을 구하려고 하는데, 계약하기 전에 확인해야 할 정부 지원 제도와 조건을 알려줘.

서비스가 다음 정보를 제공하는 방식이야.

1. 거주 지역 확인
2. 사용자 조건 입력
3. 관련 지원 제도 검색
4. 신청 자격 확인 항목 안내
5. 계약 전 확인할 사항 정리
6. 공식 신청 페이지 제공

여기서 **주거 지원금뿐 아니라 청년 주거 정책, 보증금 관련 지원, 대출 제도 등을 범위에 넣을 수 있어.**

다만 지원금·대출·보증 제도는 서로 조건과 성격이 다르므로 분류해서 안내하는 게 좋아.

---

## ⭐ 최종적으로 추천하는 프로젝트 방향

> **개인 맞춤형 전월세 정부 지원 정책 탐색 및 신청 준비 AI 서비스**
>
> 사용자의 주거 상황과 조건을 바탕으로 관련 지원 제도를 검색하고, 자격 확인 항목과 신청 준비 정보를 AI로 안내한다. 공식 정책 자료를 근거로 답변하며, 사용자가 실제로 활용할 수 있는 주거 지원 정보 탐색을 돕는다.

이 방향이면 다음 세 가지를 함께 가져갈 수 있어.

| 목표 | 달성 방향 |
|---|---|
| 실제로 필요한 서비스 | 내가 겪은 전월세 지원금 탐색 문제 해결 |
| AI 엔지니어 취업 | 검색, RAG, LLM, 백엔드, DB |
| 직접 사용 | 내 조건을 입력하고 지원 제도 확인 |

**처음부터 거대한 서비스를 만들지 말고, 실제로 사용할 수 있는 작은 버전부터 완성하는 게 좋아.**

너는 이 서비스를 **청년 1인 가구 중심으로 만들고 싶어? 아니면 나이 제한 없이 모든 전월세 거주자를 대상으로 하고 싶어?**
